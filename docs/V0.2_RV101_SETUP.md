# v0.2 — RV101 ↔ iPhone

## Transport
Use the official Rokid iOS Mobile SDK rather than raw RFCOMM. The SDK owns the supported glasses/mobile connection.

## Setup
1. Install CocoaPods if needed.
2. Run `pod install`.
3. Open the generated `.xcworkspace`.
4. Obtain Rokid developer App Key, App Secret and Access Key.
5. Copy `RokidCredentials.swift.example` to `RokidCredentials.swift` and fill the values locally.
6. Pair/connect the RV101 using the normal Rokid companion flow.
7. Launch Rokid Companion and run the connection test.

## v0.2 acceptance test
- SDK initializes without an error.
- At least one paired Rokid device is returned by `queryDeviceList`.
- The adapter selects the device.
- Speech recognized by the glasses reaches `onAsrResult` and becomes a `RokidRequest`.
- A short response can be sent back over the SDK VUI message channel.

## Security
`RokidCredentials.swift` and `Secrets.xcconfig` are ignored and must never be committed.
